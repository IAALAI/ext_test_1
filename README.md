# new tabc

一个浏览器扩展工具.接管浏览器的新标签和书签部分

提供更好的标签页与书签管理功能

目前包含标签页管理、收藏夹管理、原生分组管理和设置四个入口。

- 标签页：按窗口显示，支持搜索、切换、关闭、固定、休眠和保护。
- 收藏夹：浏览文件夹、全局搜索，创建、修改和删除书签与文件夹。
- 分组：选择同一窗口的标签页创建或加入原生分组，修改名称/颜色、折叠、移出或解散分组。解散时保留标签页。Firefox 的原生分组接口需要 139 或更新版本；接口不可用时显示提示。
- 设置：开启或关闭自动休眠，选择 2、10、30 分钟；浏览器扩展的选项页与首页设置共用配置。

自动休眠默认开启，间隔为 10 分钟。后台使用 `browser.alarms`，在关闭管理页后仍会运行，浏览器重启后恢复定时器。每次检查只处理至少对应时长未访问的后台 HTTP(S) 标签页，并按最久未访问优先排序。

实现参考 [Firefox Tab Unloading](https://firefox-source-docs.mozilla.org/browser/components/tabbrowser/docs/tab-unloading.html) 的访问顺序和保护规则，用 `browser.tabs.discard` 卸载页面，重新激活标签页时由浏览器恢复内容。扩展无法读取 Firefox 内部的内存压力、进程内存和完整 WebRTC/原生画中画状态，因此这里实现的是定时检查策略。

当前标签页、固定标签页、有声音、媒体共享、已保护、正在加载、已休眠以及浏览器/扩展页面会被排除。卸载前检查所有可访问框架中的播放媒体、画中画、可编辑区域与表单改动；无法检查时跳过。Firefox 未提供标准画中画状态时，包含视频的页面会保守跳过。数据通道通话、网页应用编辑器等状态无法完整识别，可以在标签页管理中点击“保护”。休眠前会再次检查活动状态与配置，浏览器拒绝卸载时也不会记为成功。

开发建议使用 Node.js 22.6 或更新版本。

```sh
pnpm install
npm run check
npm test
npm run package
```

`npm run package` 会重新编译，并覆盖 `web-ext-artifacts/iaalai_tabs.xpi`。Firefox 最低版本为 115（分组功能需 139）；安装/测试未签名开发包时可通过 `about:debugging` 临时加载。
